# GEO — Generative Engine Optimization Platform

High-fidelity frontend for **GEO (Generative Engine Optimization)** — an enterprise telemetry and visibility analytics suite designed to monitor, benchmark, and optimize brand presence across conversational search models and LLM answer engines (OpenAI GPT-4o, Claude 3.5 Sonnet, Perplexity Pro, Google Gemini 2.0, DeepSeek R1, Mistral, and more).

---

## 🚀 Features

- **Marketing Landing Page**:
  - Live Prompt Vector Synthesizer
  - Forensic Extraction Architecture & Framework Overview
  - Technical FAQ & Institutional Research
  - Seamless Sign In & Sign Up authentication flow (`Email`, `Company`, `Website`)
- **GEO Engine Dashboard (Intelligence v1.4)**:
  - **AI Visibility**: Mention Rate, Recommendation Rate, Top-3 Rate, Prompt Coverage, Engine Coverage, and 90-Day Trend Chart
  - **Competitive Position**: Share of Voice (SoV), Competitor Matrix, Visibility Gap, Win Rate, and Head-to-Head Comparison Battleground
  - **AI Accuracy & Trust**: Trust Dial (78.4/100), Hallucination Detection, Critical Error Triage, Attribute Breakdowns (Address, Hours, Service, Pricing), and Cross-Engine Consistency Matrix
  - **Sources & Authority**: Citation Rate, Official Source Usage, Coverage, Accuracy, Channel Diversity, Freshness, and Competitor Source Gap Explorer
  - **Opportunities & Impact**: Remediation Backlog, Critical Issues, Fix Velocity, A/B Experiment Success, and Impact per Fix decomposition
  - **Account & Workspace Settings**: Interactive profile, multi-engine scope, API keys copy tool, and billing controls
  - **Stationary Left Sidebar**: Independent scrolling on analytical canvas with stationary sidebar

## 💻 Local Development

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start the local development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173/](http://localhost:5173/) in your browser.

3. **Production build:**
   ```bash
   npm run build
   ```
